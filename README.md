# 植物大战僵尸 · 网页版

基于原版《植物大战僵尸》风格制作的网页游戏（单文件 HTML，零依赖）。

## 玩法
- 点击上方卡牌选择植物，再点击草坪种植；点击掉落的阳光收集资源
- 守住最左侧的房屋，撑过 5 波僵尸进攻即可获胜
- 能量豆：可为任意植物充能（豌豆狂暴、向日葵爆发产阳、坚果回血）

## 单位
- 植物：向日葵 / 豌豆射手 / 寒冰射手 / 坚果墙 / 樱桃炸弹 / 双发射手 / 土豆雷 / 火爆辣椒
- 僵尸：普通 / 旗帜 / 路障 / 铁桶 / 撑杆跳

## 运行
直接用浏览器打开 `index.html` 即可游玩（手机、电脑均可），或访问 GitHub Pages：
https://wh12334.github.io/plant-vs-zombies/
